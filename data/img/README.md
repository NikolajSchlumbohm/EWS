hydration\_info.json gibt an, wie die nicht unter CC-Lizenz vorliegenden Bilder rekonstruiert werden können. Dadurch kann das Dataset ohne legale Probleme weitergegeben werden.



img\_bin gibt für jedes Bild einen Binärcode an, bei dem jedes Bit angibt ob die folgenden Kategorie jeweils zutreffen:



10000 meme

01000 ort

00100 person

00010 politik

00001 text



img\_label gibt die gleichen Kategorien, allerdings menschenlesbarer an.



number\_of\_words\_per\_image gitb für jedes Bild, auf dem Wörter sind, die Anzahl an. Alle anderen Bilder sind nicht enthalten
